# Qala Balance AI — «Аким на 5 часов»

Симулятор для хакатона HackAlem AI помогает сравнивать городские решения при ограниченном бюджете. Участник выбирает пять мероприятий для условных районов Астаны и получает воспроизводимый **Astana Quality of Life Score** вместе с объяснением сильных сторон, рисков и компромиссов. Все показатели и цены синтетические; результат не является прогнозом или официальной оценкой города.

## Сценарий для жюри

1. Откройте приложение и получите одинаковые для всех стартовые данные: пять районов и бюджет **1 000 млн ₸**.
2. Выберите по одной мере для транспорта, экологии, социальной сферы, безопасности и сервисов. У районной меры укажите район; городская мера действует сразу на все пять.
3. Следите за расходом. Приложение блокирует расчёт при неполном выборе, несовместимых мерах и превышении бюджета.
4. Сравните Score и показатели районов до и после. Измените одну меру, чтобы увидеть другой результат.
5. Нажмите «Получить AI-анализ». Без ключа OpenAI отобразится детерминированный локальный анализ.

Пример допустимого набора: `M1` в Нуре, `M5` в Сарыарке, `M7` в Нуре, `M10` в Нуре и городская `M12`. Расход — **93 условные единицы = 930 млн ₸**. Пара `M10 + M12` даёт бонус безопасности улиц в Нуре. Базовый Score — **52,56**.

## Данные и правила

Источник чисел — предоставленный команде документ «Датасет районов.docx». Код хранит пять синтетических районов (Есиль, Алматы, Сарыарка, Байконур, Нура), их доли населения и десять показателей от 0 до 100. Чем выше показатель, тем лучше: `T1/T2` — транспорт, `E1/E2` — экология, `S1/S2` — соцсфера, `B1/B2` — безопасность, `C1/C2` — сервисы. Каталог содержит **14 мер `M1–M14`** с ценой, типом, задержкой эффекта и численным влиянием. Горизонт модели — восемь кварталов.

Внутренний бюджет — **100 условных единиц**; одна единица отображается как **10 млн ₸**. Остаток не увеличивает Score. Каждая мера выбирается не более одного раза. Для районной меры район обязателен, а для городской район не задаётся. Несовместимы `M1+M3` независимо от района, `M4+M7` в одном районе и `M5+M13` в одном районе.

Для хакатонного интерфейса действует дополнительное правило **ровно по одной мере из каждого из пяти направлений**. Оно конкретизирует общую задачу, но строже исходного документа: там допускаются любые пять мер при ограничении не более двух из одного направления. Поэтому комбинации двух транспортных или двух экологических мер в этой версии недоступны, как и связанные с ними синергии `M1+M2` и `M5+M6`. Синергия `M10+M12` доступна. Формула и исходные числа документа сохранены. При необходимости правило выбора можно расширить отдельным обновлением интерфейса и валидатора.

## Формула Score

Полный эффект меры по показателю умножается на долю `(8 − L) / 8`, где `L` — лаг в кварталах. Затем добавляются применимые фиксированные бонусы синергии без масштабирования лагом; каждый показатель ограничивается интервалом `0–100`.

Для каждого района `d`:

```text
D_d = 0,10·T1 + 0,10·T2 + 0,09·E1 + 0,11·E2
    + 0,11·S1 + 0,11·S2 + 0,09·B1 + 0,09·B2
    + 0,10·C1 + 0,10·C2

D_avg = Σ populationShare_d · D_d
N_crit = число пар «район × показатель» со значением строго меньше 40
Score = 0,7·D_avg + 0,3·min(D_d) − N_crit
```

Веса направлений: транспорт `0,20`, экология `0,20`, соцсфера `0,22`, безопасность `0,18`, сервисы `0,20`. Веса показателей суммируются к единице. Показатели и итоговый Score рассчитываются TypeScript-кодом; для отображения Score округляется до двух знаков. На исходных данных получается **52,56**. AI не рассчитывает бюджет и Score.

## Технологии и запуск

Next.js App Router, React, TypeScript, CSS и официальный OpenAI JavaScript SDK. Для локального запуска требуется Node.js 22 или новее и pnpm. База данных и авторизация не нужны.

```bash
pnpm install
pnpm dev
```

Откройте адрес, показанный Next.js (обычно `http://localhost:3000`). Ключ OpenAI необязателен. Если он есть, скопируйте `.env.example` в `.env.local` и заполните `OPENAI_API_KEY`. В PowerShell: `Copy-Item .env.example .env.local`. Не добавляйте `.env.local` в Git и не используйте префикс `NEXT_PUBLIC_` для ключа.

```bash
pnpm test
pnpm typecheck
pnpm lint
pnpm build
```

## Архитектура и API

```text
src/data/                районы и 14 инициатив
src/types/simulation.ts  общий контракт выбора и результатов
src/lib/scoring.ts       формула Score
src/lib/simulation.ts    проверка выбора, бюджет, эффекты и рекомендации
src/lib/fallbackAnalysis.ts  анализ без OpenAI
src/app/page.tsx         интерфейс
src/app/api/analyze/route.ts  серверный POST /api/analyze
```

Интерфейс вызывает `simulate(selection)` для мгновенного результата. Для объяснения отправляет на сервер только выбор, например:

```json
{
  "selection": {
    "transport": { "initiativeId": "M1", "districtId": "nura" },
    "ecology": { "initiativeId": "M5", "districtId": "saryarka" },
    "social": { "initiativeId": "M7", "districtId": "nura" },
    "safety": { "initiativeId": "M10", "districtId": "nura" },
    "services": { "initiativeId": "M12" }
  }
}
```

Сервер повторно проверяет выбор и вызывает `simulate()`; присланным клиентом числам он не доверяет. Успешный ответ: `{ "analysis": { "summary": "...", "strengths": ["..."], "risks": ["..."], "tradeoffs": ["..."], "recommendation": "..." }, "source": "fallback" }`. При действующем ключе `source` может быть `openai`. Неверный ввод получает HTTP 400, перерасход — HTTP 422 с суммой превышения и допустимой альтернативой.

AI использует [Responses API со Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs) и объясняет уже рассчитанные результаты на русском языке. Структура ответа проверяется на сервере; текст рекомендации берётся из проверенной симулятором замены. При отсутствии ключа, отказе, сетевой ошибке или неверном ответе модели используется детерминированный fallback.

## Ограничения и развитие

Данные и эффекты условные. Модель не учитывает реальные сметы, изменения населения, нормативные процедуры, неопределённость или операционные затраты после восьми кварталов. Для применения в управлении нужны проверенные открытые данные, методологическая экспертиза, калибровка эффекта мер и оценка чувствительности. Возможные расширения: сравнение команд, карта районов, события и экспорт отчёта.
